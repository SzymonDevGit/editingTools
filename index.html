How it works

  1. Your videostays on your computer
  2. Sound16 kHz mono
  3. Whisper + Silerothe words, and exactly when they're said
  4. autosubs.pycuts and times the lines
  5. .srtready for DaVinci Resolve

Both AI models run inside your browser. The last two steps are the same Python file as the Windows version, autosubs.py, running in the browser with Pyodide.

Use it in DaVinci Resolve

  1. File › Import › Subtitle… and pick the .srt.
  2. Drag it from the Media Pool onto the timeline above the video, starting where the clip starts.
  3. To export: Deliver › Subtitle Settings › Export Subtitle, then Burn into video or As a separate file.

Windows version

Uses the biggest Whisper model and can do many videos at once: drag them onto Subtitle.bat. See the setup guide.
