README

How it works

Your video goes through five steps. The first three use AI models that run inside your browser. The last two are the same Python file the Windows version uses, autosubs.py, running in the browser with Pyodide.

Why there are two models

Whisper is great at the words but its times can drift by a second or more after music or silence. Silero only answers "is someone talking right now?", but it answers that very precisely. autosubs.py takes the words from Whisper and the timing from Silero, so a subtitle never pops up while nobody is speaking.

How a sentence becomes subtitles

A real example from Szymon's sample clip. Each block is one subtitle. The pause of almost a second after "folder." starts a new sentence, and the long sentence after it is cut into chunks of at most 6 words, never ending on a word like "at" or "the".

Use it in DaVinci Resolve (free)

  1. File › Import › Subtitle… and pick the .srt. It lands in the Media Pool.
  2. Drag it from the Media Pool onto the timeline above the video, starting at the same point as the clip. Resolve adds a Subtitle track for it.
  3. Click the subtitle track to edit text or timing in the Inspector. To style the whole track: select the track header, then Inspector › Track (font, size, outline, position).
  4. To export: Deliver page › Subtitle Settings, tick Export Subtitle, then Burn into video for captions baked into the picture, or As a separate file for YouTube-style captions.

Run it on your PC

The Windows version uses the biggest Whisper model and can do many videos at once. Drag video files onto Subtitle.bat and an .srt appears next to each one.

  1. Download the autosubs folder and install Python 3.
  2. Add whisper.cpp, ffmpeg and the two model files. The setup guide lists where to get each one.
  3. Put your names in terms.txt and drag a video onto Subtitle.bat.
