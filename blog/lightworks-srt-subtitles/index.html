Free subtitles in Lightworks with an SRT file

Updated 9 November 2026 · by Szymon at szy.monster

Lightworks is a professional editor with a free version, and it's been used on feature films. Recent versions (2023 and later) can import and export SRT subtitles, so you can make the subtitles for free with Whisper and finish them in Lightworks.

1. Make the SRT

Open AutoSubtitler, drop in your video, and press Make subtitles. Download the .srt when it's done. Your video isn't uploaded anywhere.

If you're subtitling a finished edit, export a quick draft of the sequence first and subtitle that. The times then match the sequence.

2. Import it

Import the .srt with Lightworks' Import dialog, the same way you import media. In recent versions, subtitle files appear as a subtitle clip that you can add to the sequence. Place it so its start lines up with the start of the video it was made from.

3. Edit and style

Click a subtitle to change its text or timing. The text settings for the subtitle track control the font, size, colour and position.

4. Export

When you export, choose whether the subtitles are burned into the picture or exported as a separate file. A separate file suits YouTube, and burned-in suits social media. See burned-in vs separate subtitles.

Tips

  • If your Lightworks version doesn't offer subtitle import, update it. Subtitle support arrived in the 2023 releases.
  • The free version of Lightworks limits export resolution. If you need full-resolution output with burned-in subtitles, you can export from Lightworks without subtitles, then burn them in with HandBrake.
